{% comment %} The barcode/search input shown in the navbar. Rendered as a plain GET form by default: pages without a ``#scan-result`` container submit to the scan page, which redirects when the value is a barcode or renders text-search results otherwise. Templates that render ``#scan-result`` pass ``htmx=True`` so the value is posted to the htmx handler and the results are swapped in place. {% endcomment %}
